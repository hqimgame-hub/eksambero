Scan QR untuk Download APK di HP Siswa

Download File APK Langsung (.apk)

Ukuran file: ±18 MB • Kompatibel: Android 5.0 hingga Android 14/15

Panduan Singkat Siswa:

  1. Download file APK di atas melalui browser Chrome di HP.
  2. Jika muncul peringatan "Jenis file ini dapat membahayakan", klik Tetap Download (karena aplikasi ini dibuat mandiri untuk sekolah).
  3. Buka file hasil unduhan dan klik Install.
  4. Buka aplikasi ExamBro dan izinkan akses kamera untuk memindai QR Code ujian dari guru.
